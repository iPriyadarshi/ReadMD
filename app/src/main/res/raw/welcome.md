# Welcome to ReadMD

**ReadMD** is a simple, focused reader for Markdown files on Android.

## What it can do

- Render Markdown with **bold**, *italic*, ~~strikethrough~~, and `inline code`
- Show tables, task lists, and fenced code blocks
- Jump between headings with the **table of contents**
- Search inside the open document
- Switch to the raw Markdown source at any time
- Follow light and dark themes (follows your system setting by default)
- Remember recently opened files

## Opening files

1. Tap **Open file** and pick any `.md` file from your device
2. Or tap **Open folder** to browse every Markdown file in a folder
3. Files can also be opened from other apps via *Open with → ReadMD*
